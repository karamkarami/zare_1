# ضریب بهبود (Improvement Factor) کنسلر سه‌پالسی روی داده خام

این پوشه مستقل از بقیه پروژه است و دو فایل دارد:

| فایل | کار |
|---|---|
| `main_if.m` | اسکریپت اصلی: داده را می‌خواند، کلاتر را خودش پیدا می‌کند و IF را حساب می‌کند |
| `if_demo_data.m` | داده خام ساختگی با IF معلوم (39.1 dB) برای امتحان کردن اسکریپت |

## اجرا

1. در بخش `Settings` بالای `main_if.m`، مسیر فایل را در `dataFile` بنویسید. اگر خالی بماند، داده دمو اجرا می‌شود.
2. داده باید ماتریس مختلط باشد: **هر سطر یک PRI و هر ستون یک سلول برد**. اگر برعکس است، `pulsesInRows = false` بگذارید.
3. `main_if` را اجرا کنید.

| تنظیم | پیش‌فرض | معنی |
|---|---|---|
| `dataVar` | `''` | نام متغیر داخل فایل. اگر خالی باشد، بزرگ‌ترین متغیر عددی برداشته می‌شود |
| `pris` | `[]` | PRIهایی که استفاده می‌شوند، مثلا `1:300` |
| `firstCell` | `1` | اولین سلول برد. نشتی فرستنده و blanking اول برد را کنار می‌گذارد |
| `decoderTaps` | `[]` | اختیاری: ضرایب دیکدر در راستای برد. به‌طور پیش‌فرض داده خام استفاده می‌شود |
| `priStep` | `1` | اگر دو پالس یک‌درمیان (PRI به PRI) عوض می‌شوند، `2` بگذارید |
| `minCnrDb` | `20` | سلول کلاتر دست‌کم این مقدار بالاتر از نویز است |
| `maxDoppler` | `0.05` | داپلر میانگین سلول کلاتر کمتر از این کسر از PRF است |
| `outlierDb` | `10` | سلولی که IFش این مقدار پایین‌تر از میانه باشد کنار گذاشته می‌شود (هدف متحرک داخل کلاتر) |

## روش

1. **نویز:** میانگین توان هر سلول برد حساب می‌شود. آرام‌ترین سلول‌ها فقط نویز دارند. نویز برابر میانه سلول‌هایی است که حداکثر 1.8 dB بالاتر از صدک دهم هستند. DC offset گیرنده هم از همین سلول‌ها تخمین زده و کم می‌شود.
2. **پیدا کردن کلاتر:** سلولی کلاتر است که CNR آن از `minCnrDb` بیشتر باشد و داپلر میانگینش (pulse pair) نزدیک صفر باشد. سلول‌هایی که هدف متحرک دارند (هواپیما، ماشین، پرنده) کنار گذاشته می‌شوند.
3. **کنسلر:** خروجی کنسلر `y(m) = x(m) - 2x(m-1) + x(m-2)` است.
4. **ضریب بهبود:**

```
Cin  = Pin  - N          توان کلاتر ورودی
Cout = Pout - 6N         کلاتر باقی‌مانده در خروجی (بهره نویز کنسلر 1+4+1 = 6 است)
CA   = ΣCin / ΣCout      تضعیف کلاتر
IF   = 6 · CA            یعنی IF = CA + 7.8 dB
```

عدد 6 میانگین بهره کنسلر برای هدف‌ها روی همه داپلرهاست. برای همین `IF = (S/C)out / (S/C)in = 6·Cin/Cout` است. مقدار `6·ΣPin/ΣPout` (بدون کم کردن نویز) هم چاپ می‌شود که همیشه یک کران پایین برای IF است.

خروجی‌ها: IF کل، میانه IF تک‌تک سلول‌ها و چهار نمودار. نمودارها تصویر داده، توان هر سلول قبل و بعد از کنسلر، IF هر سلول و طیف داپلر کلاتر همراه با پاسخ کنسلر را نشان می‌دهند.

## دیکدر لازم است؟

**نه.** دیکدر در راستای برد (fast time) فیلتر می‌کند و کنسلر در راستای پالس‌ها (slow time). هر دو خطی و تغییرناپذیر با زمان‌اند و روی دو بعد جدا کار می‌کنند. پس ترتیبشان مهم نیست:

```
canceler(decoder(X)) = decoder(canceler(X))
```

یعنی کنسلر سه‌پالسی را می‌شود مستقیم روی داده خام اعمال کرد. ضریب بهبود به پایداری پالس به پالس کلاتر بستگی دارد (حرکت کلاتر، نویز فاز اسیلاتور، ناپایداری فرستنده و jitter زمانی). این پایداری با دیکدر عوض نمی‌شود. روی داده دمو، که هر PRI هر دو پالس را دارد (Barker 13 و کد 64 چیپی):

| پردازش | IF اندازه‌گیری‌شده |
|---|---|
| داده خام | 38.9 dB |
| بعد از دیکدر پالس بلند | 38.7 dB |
| بعد از دیکدر پالس کوتاه | 38.9 dB |
| مقدار واقعی | 39.1 dB |

اختلاف دو ترتیب (دیکدر بعد کنسلر و برعکس) در حد دقت عددی است (`5e-15`).

### شرط‌ها و دام‌ها (اسکریپت همه را چک می‌کند)

* **اشباع ADC:** اگر کلاتر نزدیک ADC را اشباع کند، سیستم قبل از هر پردازش دیجیتال غیرخطی شده است. در این حالت ترتیب پردازش هم کمکی نمی‌کند و IF محدود می‌شود. اسکریپت نمونه‌هایی را که روی بیشترین مقدار جمع شده‌اند می‌شمارد و هشدار می‌دهد.
* **پالس‌های یک‌درمیان:** دیکدر و کنسلر فقط وقتی جابه‌جاپذیرند که شکل موج همه PRIها یکی باشد. اگر دو پالس PRI به PRI عوض شوند، کنسلر باید PRIهای هم‌نوع را از هم کم کند (`priStep = 2`). اسکریپت همبستگی lag 1 و lag 2 را چاپ می‌کند. اگر lag 2 خیلی بیشتر از lag 1 باشد، هشدار می‌دهد.
* **نشتی فرستنده در اول برد:** نشتی خیلی پایدار است و IF را بیش از واقع خوب نشان می‌دهد. در دمو، 20 سلول نشتی IF را از 38.9 به 42.7 dB رساند. اسکریپت سلول‌هایی را که خیلی پایدارتر از بقیه هستند گزارش می‌دهد. `firstCell` را بعد از آن‌ها بگذارید.
* **نویز:** IF اندازه‌گیری‌شده نمی‌تواند از CNR کلاتر بیشتر شود. اگر کلاتر باقی‌مانده زیر نویز باشد، فقط کران پایین چاپ می‌شود.

### دیکدر کجا کمک می‌کند؟

فقط وقتی که IF به نویز محدود شده باشد. دیکدر CNR کلاتر **نقطه‌ای** (ساختمان، دکل) را به اندازه بهره فشرده‌سازی بالا می‌برد و سقف IF قابل اندازه‌گیری را بالاتر می‌برد. برای کلاتر **گسترده**، CNR بعد از دیکدر تقریبا همان می‌ماند. دیکدر کلاتر را در برد هم جمع می‌کند، پس محل کلاتر روی نمودار دقیق‌تر دیده می‌شود. برای امتحان روی دمو:

```matlab
[~, dd] = if_demo_data();  decoderTaps = conj(fliplr(dd.long));
```

اسکریپت در MATLAB R2016b به بعد اجرا می‌شود و به هیچ toolboxی نیاز ندارد. در GNU Octave هم اجرا می‌شود.
