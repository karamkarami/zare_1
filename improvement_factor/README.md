# ضریب بهبود (Improvement Factor) کنسلر سه‌پالسی روی داده خام

این پوشه مستقل از بقیه پروژه است و دو فایل دارد:

| فایل | کار |
|---|---|
| `main_if.m` | اسکریپت اصلی: داده را می‌خواند، سلول‌های کلاتر را پیدا می‌کند و IF را حساب می‌کند |
| `if_demo_data.m` | داده خام ساختگی برای امتحان کردن اسکریپت: کلاتر زمین با IF معلوم (39.1 dB)، یک هدف متحرک و یک هدف تست ثابت در سلول 1000 (یک حلقه روی PPI، با IF برابر 70 dB) |

## اجرا

1. در بخش `Settings` بالای `main_if.m`، مسیر فایل را در `dataFile` بنویسید. اگر خالی بماند، داده دمو اجرا می‌شود.
2. داده باید ماتریس مختلط باشد: **هر سطر یک PRI و هر ستون یک سلول برد**. اگر برعکس است، `pulsesInRows = false` بگذارید.
3. `main_if` را اجرا کنید.

| تنظیم | پیش‌فرض | معنی |
|---|---|---|
| `dataVar` | `''` | نام متغیر داخل فایل. اگر خالی باشد، بزرگ‌ترین متغیر عددی برداشته می‌شود |
| `pris` | `[]` | PRIهایی که استفاده می‌شوند، مثلا `1:300` |
| `firstCell` | `1` | اولین سلول برد. نشتی فرستنده و blanking اول برد را کنار می‌گذارد |
| `clutterCells` | `[]` | سلول‌هایی که کلاتر حساب می‌شوند، هر سطر یک `[اول آخر]`. مثال: `[1 400]`، یا `[995 1015; 1040 1110]` برای دو پژواک هدف تست. اگر خالی باشد، در کل برد جستجو می‌شود |
| `skipCells` | `[]` | سلول‌هایی که کنار گذاشته می‌شوند، مثلا `[990 1110]` |
| `decoderTaps` | `[]` | اختیاری: ضرایب دیکدر در راستای برد. به‌طور پیش‌فرض داده خام استفاده می‌شود |
| `priStep` | `1` | اگر دو پالس یک‌درمیان (PRI به PRI) عوض می‌شوند، `2` بگذارید |
| `minCnrDb` | `20` | سلول کلاتر دست‌کم این مقدار بالاتر از نویز است |
| `maxDoppler` | `0.05` | داپلر میانگین سلول کلاتر کمتر از این کسر از PRF است |
| `outlierDb` | `10` | سلولی که IFش این مقدار پایین‌تر از میانه باشد کنار گذاشته می‌شود (هدف متحرک داخل کلاتر) |

### اندازه‌گیری روی هدف تست

هدف تستی که در همه PRIها در یک برد ثابت است (حلقه روی PPI) سرعت ندارد. پس یک «کلاتر» ایده‌آل است. خودش هیچ تغییری نمی‌کند، پس هر چه از آن بعد از کنسلر باقی بماند از ناپایداری خود رادار است.

1. اسکریپت را یک بار بدون محدودیت اجرا کنید. در جدول قطعه‌ها، دو پژواک هدف تست (پالس کوتاه و پالس بلند) با `steady` نزدیک 100 % دیده می‌شوند.
2. برد این دو پژواک را، با چند سلول حاشیه، در `clutterCells` بگذارید. مثال: `clutterCells = [995 1015; 1040 1110]`.
3. IF هر پژواک جدا و IF هر دو با هم چاپ می‌شود. سهم داپلر، دامنه و فاز هم جدا چاپ می‌شود (بخش 7 زیر).

## نحوه محاسبه

### 1. داده و نمادها

`x(m, r)` نمونه مختلط PRI شماره `m` (از 1 تا M) در سلول برد `r` است. همه محاسبه‌ها برای هر سلول برد جدا، در راستای PRIها (slow time) انجام می‌شود.

### 2. توان ورودی و نویز

میانگین توان هر سلول:

```
Pin(r) = (1/M) Σm |x(m, r)|²
```

کلاتر فقط بخشی از برد را می‌پوشاند، پس آرام‌ترین سلول‌ها فقط نویز دارند:

1. صدک دهم `Pin` حساب می‌شود.
2. سلول‌هایی که کمتر از 1.8 dB بالاتر از آن هستند «سلول‌های آرام» حساب می‌شوند.
3. توان نویز `N` میانه `Pin` در سلول‌های آرام است.

DC offset گیرنده در همه سلول‌ها مثل یک کلاتر کاملا پایدار دیده می‌شود. برای همین میانگین مختلط سلول‌های آرام از کل داده کم می‌شود.

### 3. انتخاب سلول‌های کلاتر

سلولی کلاتر است که هر سه شرط را داشته باشد:

1. **قوی باشد:** `CNR(r) = Pin(r)/N - 1` دست‌کم `minCnrDb` باشد.
2. **سرعت نداشته باشد:** داپلر میانگین با روش pulse pair حساب می‌شود و باید نزدیک صفر باشد:

    ```
    R1(r) = mean( x(m, r) · conj(x(m-1, r)) )
    f(r)  = angle(R1) / 2π                   (کسری از PRF)
    |f(r)| <= maxDoppler
    ```

3. **داخل `clutterCells` و بیرون از `skipCells` باشد.**

بعد از کنسلر، سلول‌هایی که IFشان بیش از `outlierDb` پایین‌تر از میانه است حذف می‌شوند. این سلول‌ها یک هدف متحرک دارند که از کنسلر رد شده است.

### 4. کنسلر سه‌پالسی

```
y(m) = x(m) - 2·x(m-1) + x(m-2)          ضرایب w = [1 -2 1]
```

پاسخ فرکانسی کنسلر (`f` کسری از PRF است):

```
H(f)   = 1 - 2e^(-j2πf) + e^(-j4πf) = (1 - e^(-j2πf))²
|H|²   = 16 sin⁴(πf)                     در f = 0 صفر، در f = PRF/2 برابر 16 (12 dB)
```

بهره کنسلر برای نویز سفید برابر مجموع مربع ضرایب است:

```
G = 1² + 2² + 1² = 6                     (7.8 dB)
```

`G` میانگین `|H(f)|²` روی همه داپلرها هم هست. پس بهره میانگین کنسلر برای هدف‌ها با داپلر یکنواخت هم برابر 6 است.

توان خروجی هر سلول:

```
Pout(r) = (1/(M-2)) Σm |y(m, r)|²
```

### 5. ضریب بهبود

تعریف (IEEE): نسبت سیگنال به کلاتر در خروجی، تقسیم بر همین نسبت در ورودی. سیگنال روی همه داپلرهای ممکن میانگین گرفته می‌شود:

```
IF = (S/C)out / (S/C)in = (S·G / Cout) / (S / Cin) = G · Cin / Cout
CA = Cin / Cout                          تضعیف کلاتر
IF = G · CA     →     IF[dB] = CA[dB] + 7.8 dB
```

نویز با کلاتر جمع می‌شود. نویز ورودی `N` است و نویز خروجی `G·N`:

```
Pin  = Cin  + N       →   Cin  = Pin  - N
Pout = Cout + G·N     →   Cout = Pout - G·N
```

برای یک گروه از سلول‌ها (یک قطعه یا همه سلول‌های کلاتر)، توان‌ها اول جمع می‌شوند و بعد تقسیم:

```
IF = G · Σr Cin(r) / Σr Cout(r)
```

پس IF گروه با توان وزن داده می‌شود و قوی‌ترین سلول‌ها آن را تعیین می‌کنند.

**محدودیت نویز:**

- `G·ΣPin/ΣPout` (بدون کم کردن نویز) همیشه کمتر یا مساوی IF واقعی است و یک کران پایین است.
- اگر کلاتر باقی‌مانده کمتر از 10 % نویز خروجی باشد، فقط همین کران پایین چاپ می‌شود (با `>=`).
- IF اندازه‌گیری‌شده نمی‌تواند خیلی از CNR بیشتر شود. پس برای اندازه‌گیری IF برابر 70 dB، CNR باید دست‌کم 70 تا 80 dB باشد.
- برای یک هدف نقطه‌ای، دیکدر CNR را به اندازه بهره فشرده‌سازی بالا می‌برد. در دمو، کد 64 چیپی CNR را از 80 به 98 dB رساند.

### 6. قطعه‌های کلاتر

سلول‌های کلاتر پشت سر هم (با فاصله حداکثر 3 سلول) یک قطعه‌اند. جدول اسکریپت برای هر قطعه این‌ها را نشان می‌دهد:

- برد
- بیشترین CNR
- سهم از توان کلاتر
- `steady`: سهمی از توان که در همه PRIها یکی است (بخش 7)
- IF

چون هر PRI دو پالس دارد، یک هدف ثابت در داده خام دو بار دیده می‌شود: یک پژواک از پالس کوتاه و یک پژواک از پالس بلند. روی داده دمو:

```
     cells        max CNR   power share   steady       IF
   1043 - 1106    79.9 dB      79.7 %   100.0 %       69.8 dB    <- هدف تست، پالس بلند
   1000 - 1012    79.9 dB      16.2 %   100.0 %       69.7 dB    <- هدف تست، پالس کوتاه
      1 - 299     66.1 dB       4.1 %     4.7 %       38.9 dB    <- کلاتر زمین
```

| سلول‌های کلاتر | IF کل |
|---|---|
| بدون محدودیت (هدف تست و کلاتر زمین با هم) | 52.6 dB |
| `skipCells = [990 1110]` (فقط کلاتر زمین) | 38.9 dB (واقعی 39.1) |
| `clutterCells = [990 1110]` (فقط هدف تست) | 69.8 dB (واقعی 70.0) |

اگر IF کل خیلی بالاتر از میانه IF سلول‌ها باشد، اسکریپت هشدار می‌دهد و قطعه‌ای را که عدد را تعیین کرده نام می‌برد.

### 7. پژواک ثابت (هدف تست): چه چیزی IF را محدود می‌کند

یک پژواک ثابت را می‌شود این‌طور نوشت:

```
x(m) = s · (1 + a(m)) · e^(j(2π·f·m + φ(m)))
```

- `s` پژواک ثابت است.
- `a(m)` تغییر نسبی دامنه از پالس به پالس است.
- `φ(m)` تغییر فاز است (نویز فاز اسیلاتورها، jitter زمانی).
- `f` یک داپلر ثابت است. مثلا وقتی مولد هدف تست با رادار قفل نیست.

اسکریپت اول داپلر هر سلول را جبران می‌کند و میانگین می‌گیرد تا پژواک ثابت `ref(m)` به دست بیاید. `steady = Σ|ref|² / ΣPin` است. اگر بیشتر از 90 % باشد، قطعه «ثابت» است. چون کنسلر خطی است، خروجی آن سه بخش دارد:

| بخش | محاسبه | اگر تغییرات از پالسی به پالس دیگر مستقل باشند |
|---|---|---|
| داپلر | `canc(ref)`: خروجی کنسلر از خود پژواک ثابت | `IF = 6 / (16 sin⁴(πf))` |
| دامنه | بخش هم‌فاز با پژواک در `canc(x - ref)` | `IF = 1 / σa²` |
| فاز | بخش 90 درجه با پژواک در `canc(x - ref)` | `IF = 1 / σφ²` (σφ به رادیان) |

هر کدام از دو بخش آخر نصف نویز خروجی (`G·N/2`) را دارد و آن هم کم می‌شود. IF کل از سه بخش این‌طور به دست می‌آید:

```
1/IF = 1/IFdoppler + 1/IFamplitude + 1/IFphase
```

اثبات `1/σφ²` (با فرض فاز کوچک): `x(m) ≈ s·(1 + jφ(m))`. بخش ثابت `s` در کنسلر صفر می‌شود (1 − 2 + 1 = 0)، پس:

```
y(m)   = j·s·(φ(m) - 2φ(m-1) + φ(m-2))
|y|²   = |s|² · (1 + 4 + 1) · σφ² = 6·|s|²·σφ²
IF     = 6 · |s|² / (6·|s|²·σφ²) = 1/σφ²
```

برای دامنه هم همین‌طور است. اگر تغییرات کند باشند (همبسته از پالسی به پالس دیگر)، کنسلر بیشتر آن‌ها را حذف می‌کند و IF بالاتر از `1/σ²` می‌شود. عددی که اسکریپت چاپ می‌کند همیشه IF واقعی هر بخش است.

| IF | jitter فاز معادل | jitter دامنه معادل | داپلر ثابت معادل |
|---|---|---|---|
| 50 dB | 0.18° rms | 0.32 % | 0.014 PRF |
| 60 dB | 0.057° rms | 0.10 % | 0.0079 PRF |
| 70 dB | 0.018° rms | 0.032 % | 0.0044 PRF |
| 80 dB | 0.0057° rms | 0.010 % | 0.0025 PRF |

مثال: هدف تستی با jitter دامنه 0.1 %، jitter فاز 0.018° و داپلر 0.002 PRF اندازه‌گیری شد:

| بخش | محاسبه‌شده | اندازه‌گیری‌شده |
|---|---|---|
| داپلر | 83.8 dB | 83.8 dB |
| دامنه | 60.0 dB | 59.8 dB |
| فاز | 70.0 dB | 69.9 dB |
| کل | 59.6 dB | 59.4 dB |

IF هدف تست پایداری مسیری است که سیگنال تست از آن رد می‌شود. اگر سیگنال تست از RF و با اسیلاتورهای خود رادار تزریق شود، این عدد سقف پایداری سیستم است. ولی حرکت کلاتر واقعی و مدولاسیون چرخش آنتن در آن نیست. برای کلاتر زمین با پهنای طیف داپلر `σf`، نظریه می‌گوید `IF ≈ 2·(PRF / (2π·σf))⁴`. این مقدار معمولا از سقف پایداری سیستم کمتر است.

## دیکدر لازم است؟

**نه.** دیکدر در راستای برد (fast time) فیلتر می‌کند و کنسلر در راستای پالس‌ها (slow time). هر دو خطی و تغییرناپذیر با زمان‌اند و روی دو بعد جدا کار می‌کنند. پس ترتیبشان مهم نیست:

```
canceler(decoder(X)) = decoder(canceler(X))
```

یعنی کنسلر سه‌پالسی را می‌شود مستقیم روی داده خام اعمال کرد. ضریب بهبود به پایداری پالس به پالس بستگی دارد و این پایداری با دیکدر عوض نمی‌شود. روی داده دمو، که هر PRI هر دو پالس را دارد (Barker 13 و کد 64 چیپی)، با `clutterCells = [1 800]`:

| پردازش | IF اندازه‌گیری‌شده |
|---|---|
| داده خام | 38.9 dB |
| بعد از دیکدر پالس بلند | 38.7 dB |
| بعد از دیکدر پالس کوتاه | 38.9 dB |
| مقدار واقعی | 39.1 dB |

اختلاف دو ترتیب (دیکدر بعد کنسلر و برعکس) در حد دقت عددی است (`5e-15`). دیکدر فقط وقتی کمک می‌کند که IF به نویز محدود شده باشد (بخش 5). برای امتحان روی دمو:

```matlab
[~, dd] = if_demo_data();  decoderTaps = conj(fliplr(dd.long));
```

## چیزهایی که اسکریپت چک می‌کند

* **اشباع ADC:** اگر ADC اشباع شود، سیستم قبل از هر پردازش دیجیتال غیرخطی شده و IF محدود می‌شود. اسکریپت نمونه‌هایی را که دقیقا روی بیشترین (یا کمترین) مقدار جمع شده‌اند می‌شمارد و هشدار می‌دهد.
* **پالس‌های یک‌درمیان:** دیکدر و کنسلر فقط وقتی جابه‌جاپذیرند که شکل موج همه PRIها یکی باشد. اگر دو پالس PRI به PRI عوض شوند، کنسلر باید PRIهای هم‌نوع را از هم کم کند (`priStep = 2`). اسکریپت همبستگی lag 1 و lag 2 را چاپ می‌کند. اگر lag 2 خیلی بیشتر از lag 1 باشد، هشدار می‌دهد.
* **نشتی فرستنده در اول برد:** نشتی خیلی پایدار است. اگر کلاتر زمین را اندازه می‌گیرید، نشتی IF را بیش از واقع خوب نشان می‌دهد. در دمو، 20 سلول نشتی IF کلاتر نزدیک را از 38.9 به 42.7 dB رساند. `firstCell` را بعد از آن‌ها بگذارید.
* **سلول‌های خیلی پایدار:** اسکریپت سلول‌هایی را که خیلی پایدارتر از بقیه هستند جدا گزارش می‌دهد (هدف تست، delay line، نشتی).

اسکریپت در MATLAB R2016b به بعد اجرا می‌شود و به هیچ toolboxی نیاز ندارد. در GNU Octave هم اجرا می‌شود.
